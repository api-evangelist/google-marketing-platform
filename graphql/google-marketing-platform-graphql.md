# Google Marketing Platform GraphQL API

Google Marketing Platform Admin API covers organization management, accounts, user links, property access, and integration between GMP products including Analytics, Campaign Manager, and Display & Video 360.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Google Marketing Platform REST API
**Documentation:** https://developers.google.com/marketing-platform/devguides/api/admin/v1/rest
