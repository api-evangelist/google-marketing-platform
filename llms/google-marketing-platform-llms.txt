# Google Marketing Platform Admin

> The Google Marketing Platform Admin API is the administrative control plane for a Google Marketing Platform organization. It manages links between a GMP organization and Google Analytics accounts, sets the service level of Analytics properties (STANDARD or paid 360), and reports per-property event usage and billing. It is REST + gRPC, OAuth 2.0 only, and at ALPHA launch stage. This file was GENERATED by API Evangelist from the provider's published artifacts on 2026-08-13 — the provider serves no /llms.txt (404 on developers.google.com and marketingplatform.google.com).

## Facts an agent needs first

- Base URL: https://marketingplatformadmin.googleapis.com
- Version: v1alpha (URI path). Discovery revision 20260813.
- Stability: ALPHA — "an unstable early preview stage". The Google APIs Terms of Service deprecation commitment does NOT cover alpha features.
- Auth: OAuth 2.0 authorization code only. No API keys. `Authorization: Bearer <token>`.
- Scopes: `https://www.googleapis.com/auth/marketingplatformadmin.analytics.read` (read), `https://www.googleapis.com/auth/marketingplatformadmin.analytics.update` (write).
- A Cloud quota project is REQUIRED and is not set by default. Without it, correctly authenticated calls still fail.
- Identifiers are full relative resource names: `organizations/{org_id}`, `organizations/{org_id}/analyticsAccountLinks/{link_id}`. Never bare ids.
- Pagination: `pageSize` + `pageToken` in, `nextPageToken` out.
- Rate limits: 1,200 requests/min and 300 writes/min per project; 600 and 120 per user. Exhaustion returns **HTTP 403 with reason `rateLimitExceeded`, not 429**. No rate-limit response headers.
- Errors: Google JSON envelope (`error.code`, `error.message`, `error.status`, `error.errors[].reason`). NOT RFC 9457 problem+json. Branch on `error.errors[].reason` or `error.status`.
- Idempotency: none. `createAnalyticsAccountLink` has no replay protection — list before retrying.
- Events: none. No webhooks, no streaming, no AsyncAPI.

## Operations

- `listOrganizations` — GET /v1alpha/organizations — list GMP organizations the caller can access.
- `getOrganization` — GET /v1alpha/{name} — look up one organization. (Discovery only; absent from the OpenAPI in this repo.)
- `listAnalyticsAccountLinks` — GET /v1alpha/{parent}/analyticsAccountLinks — list Analytics accounts linked to an organization.
- `createAnalyticsAccountLink` — POST /v1alpha/{parent}/analyticsAccountLinks — link an Analytics account. Write scope. Not idempotent.
- `deleteAnalyticsAccountLink` — DELETE /v1alpha/{name} — unlink an Analytics account. Write scope. Destructive.
- `setPropertyServiceLevel` — POST /v1alpha/{analyticsAccountLink}:setPropertyServiceLevel — set a property to STANDARD or 360. Write scope. Commercially consequential.
- `reportPropertyUsage` — POST /v1alpha/{organization}:reportPropertyUsage — per-property event usage plus BillInfo. (Discovery only.)
- `findSalesPartnerManagedClients` — POST /v1alpha/{organization}:findSalesPartnerManagedClients — clients managed by a sales partner. (Discovery only.)
